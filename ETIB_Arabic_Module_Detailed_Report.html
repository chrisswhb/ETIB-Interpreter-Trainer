ETIB Arabic Module: Pronunciation, Tashkeel and Tanween Error Detection

Download the Word report (.docx)

Date: 30 June 2026

Scope: Arabic evaluation component only: final tashkeel, i'rab, tanween, and pronunciation feedback.

Architecture Summary

The system uses a hybrid reference-guided architecture: Groq LLaMA diacritizes arbitrary Arabic text, Groq Whisper scores competing pronunciation hypotheses, and three local wav2vec2 Arabic models plus word-aware LLR provide backup acoustic evidence.

Problems and Limitations

  • Arabic ASR usually omits harakat, so short vowels are difficult to prove acoustically.
  • Tanween may be normalized to bare words or long-vowel spellings.
  • Word timing is approximate; a true forced aligner would improve LLR.
  • Groq requires a valid API key and internet access.
  • Automatic diacritization should be reviewed for important grammar examples.

Accuracy Claim

The realistic target is above 70% on clean, controlled recordings with fully diacritized reference text or Groq-assisted diacritization. A stable 80%+ on arbitrary Arabic text requires stronger alignment or training data.
